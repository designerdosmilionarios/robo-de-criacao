================================================================================
  INSTRUÇÕES DE USO
================================================================================

CAMINHO A (recomendado): prompt visual direto em cada bloco "Gerar Imagem"
----------------------------------------------------------------------
1. Abra http://localhost:3000 e entre na aba "Esteira IA".
2. Crie 1 bloco "Copys", clique em "📋 Colar" e cole o bloco COPYS acima.
   → Vai aparecer "9 copys detectadas". Clique "Aplicar 9 copys".
3. Crie 9 blocos "🖼️ Gerar Imagem" (clique 9 vezes no botão verde da toolbar).
4. Em cada bloco verde "Gerar Imagem", cole o PROMPT VISUAL 01..09
   diretamente na caixa verde "Prompt Visual deste bloco".
5. Conecte apenas:
     Copys → Imagem 1, Copys → Imagem 2, ..., Copys → Imagem 9
   (9 conexões — não precisa conectar o Briefing!)
6. Clique no botão "▶ Executar Todos" na toolbar.
7. Aguarde ~80 segundos. Os 9 cards aparecem.
8. Clique "📦 ZIP Todos" para baixar esteira-individual-{timestamp}.zip.

CAMINHO B (alternativo): prompt visual dentro de cada copy
----------------------------------------------------------
1. Crie 1 bloco "Briefing" (opcional, pode ficar vazio).
2. Crie 1 bloco "Copys", clique em "📋 Colar", cole COPYS.
3. Crie 9 blocos "🖼️ Gerar Imagem".
4. Em cada COPY do bloco amarelo, cole o PROMPT VISUAL na caixa "📷 Prompt Visual".
5. Conecte:
     Briefing → Imagem 1..9
     Copys → Imagem 1..9
   (18 conexões)
6. ▶ Executar Todos.

PRIORIDADE DOS PROMPTS (do mais alto para o mais baixo):
  1. Prompt Visual dentro do bloco "Gerar Imagem"  ← prioridade máxima
  2. Prompt Visual dentro da copy emparelhada       ← usado se o item 1 estiver vazio
  3. Briefing global conectado                      ← usado se os anteriores estiverem vazios
